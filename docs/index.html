01 — 核心能力Capabilities

把 coding agent 拆成
可测试、可扩展 的部件 Decompose a coding agent into
testable, extensible parts

01

结构化 Agent 循环Structured agent loop

CodingAgentHarness 统一消费 provider 流式事件——text、reasoning、tool_use、tool_result 与 final answer——在一个循环中完成全部交互。CodingAgentHarness consumes provider stream events — text, reasoning, tool_use, tool_result and final answers — in one closed loop.

02

三种执行模式Three execution modes

plan 只读勘察，build 允许写入，act 逐步确认；findLast 规则引擎按序覆盖权限，HITL 审批贯穿始终。plan reads, build writes, act confirms each step; a findLast rule engine resolves permissions with HITL approval throughout.

03

工具并发分区Tool concurrency

只读且并发安全的工具并行执行；写操作与高风险命令保持串行。edit_file 采用 read-before-edit SHA256 指纹校验。Read-only, concurrency-safe tools run in parallel while writes and risky commands stay serial. edit_file enforces read-before-edit with SHA256 fingerprint checks.

04

权限、审计与沙箱Permissions, audit & sandbox

PermissionEngine 统一权限判定与脱敏；JsonlAuditLogger 记录审计日志；Linux 下 Agent shell 默认在 bubblewrap 沙箱中运行（网络隔离与路径保护）。PermissionEngine centralizes gating and redaction; JsonlAuditLogger persists an audit trail; Linux agent shell runs inside a bubblewrap sandbox by default (network isolation & path protection).

05

上下文换窗与会话恢复Context rollover & session resume

窗口默认在模型容量的 95% 自动重开，不生成摘要；完整历史保留为可检索事实，NOTE.md 保存跨窗口工作状态。Windows roll over at 95% of the model capacity without summaries; searchable history remains the source of truth and NOTE.md carries working state across windows.

06

记忆、MCP 与 HooksMemory, MCP & hooks

MEMORY.md 与用户级记忆库是可审查的长期事实源，BM25 按需检索；MCP stdio server 自动发现注册；外部 hooks 响应事件。MEMORY.md plus a user-level store form an auditable long-term memory with BM25 retrieval; MCP stdio servers are discovered automatically; external hooks react to events.

02 — 快速开始Quick Start

克隆、安装、直接对话 Clone, install, start talking

1

克隆并安装Clone & install

使用 uv 以 editable 模式安装（Linux 默认沙箱需要 bubblewrap / bwrap）。Install in editable mode with uv (Linux default sandbox requires bubblewrap / bwrap).

2

配置 ProviderConfigure a provider

运行 xcode setup 交互向导，或配置 OpenAI / DeepSeek / ChatGLM / MiMo profile。Run the interactive xcode setup wizard, or configure an OpenAI / DeepSeek / ChatGLM / MiMo profile.

3

启动会话Launch a session

默认进入 TUI；cli 进入 REPL；-p 直接提问。--resume 可恢复历史会话。Default launches TUI; cli enters REPL; -p asks a single question. --resume picks a previous session.

沙箱与安全：Linux 下 Agent 的 bash 命令默认在 bubblewrap 沙箱中运行（工作区与 /tmp 可写、宿主其余路径只读、凭据遮蔽、网络隔离）；权限引擎与自动 reviewer 负责操作审批。 Sandbox & Safety: On Linux, agent bash commands run inside a bubblewrap sandbox by default (writable workspace & /tmp, read-only host, credential masking, network isolation); the permission engine and auto-reviewer handle operation approvals.

Shell 
git clone https://github.com/reddishJade/xcode.git
cd xcode
uv pip install -e .

xcode setup          # 首次配置向导 (Provider & API Key)
xcode config         # 交互式设置浏览器 (执行模式/审批策略/Shell)

xcode                # 进入 TUI
xcode cli            # REPL 模式
xcode -p "..."       # 单发提问
xcode -p "..." xcode tui xcode cli xcode --resume xcode config

03 — 实战场景Workflows

你可以用 Xcode 做什么 What you can do with Xcode

>_

勘察与理解代码库Understand your codebase

利用只读并发调度快速检索符号、分析目录结构，或使用 @file 注入精准上下文，快速理清复杂系统。Search symbols, map dependencies with concurrent reads, or inject exact context with @file to grok unfamiliar systems.

⚑

Plan 规划与 Build 实施Plan and build features

在 /plan 模式下零副作用产出架构方案与文件清单；切换至 /build 模式由沙箱与审查器守卫全自动落地。Produce zero-side-effect plans in /plan mode, then switch to /build mode to implement features safely under sandbox gating.

⎇

会话分支与快照撤销Branching and snapshot undo

大胆尝试实验性重构；随时用 /fork 开启新分支探索，或用 /undo 瞬间原子回滚所有受影响的文件变更。Explore refactors freely; use /fork to branch off a previous turn, or /undo to atomically restore modified files.

⬡

连接 MCP 工具生态Extend with MCP tools

通过标准 MCP stdio 协议直连本地数据库、外部 API 或自定义服务，动态扩充 Agent 的专业工具箱。Plug into local databases, APIs, or custom servers via standard MCP stdio protocol with dynamic tool discovery.

◈

跨会话长期记忆Long-horizon memory

项目约定与个人偏好持久化落盘，Agent 在需要时通过 BM25 自主检索，告别多轮对话中重复输入背景。Store durable project rules and user preferences; the agent searches memory on-demand without cluttering turn context.

⚡

外部 Hooks 自动化Event-driven hooks

在工具调用前后挂载外部脚本，实现命令执行前的动态安全判定、代码生成后的自动格式化与审计通知。Attach external scripts before or after tool runs for dynamic policy gating, automatic formatting, or audit notifications.

产品工具装配Product tool assembly

文件读写编辑、glob/grep、bash、subagent、webfetch/websearch 等。File read/write/edit, glob/grep, bash, subagent, webfetch/websearch, and more.

06 — 评估Evaluation

用 Benchmark 量化 关键设计 Measure the key design choices

真实 API 调用Real API calls

长程任务换窗消融Long-horizon rollover

同模型、同温度、同任务配对运行：不换窗 baseline vs 启用无摘要换窗的 Xcode 配置。测试进程判定任务成功，文件哈希与禁止路径判定状态保持。Paired runs with the same model, temperature, and task: a no-rollover baseline vs Xcode with summary-free context rollover. Task success is judged by tests; state retention is judged by file hashes and forbidden paths.

Shell 
uv run python -m benchmarks.runners.run_ablation \
  benchmarks/tasks/long_horizon \
  --repeat 3 --temperature 0 \
  --max-pair-attempts 2 --require-complete-usage
不调用模型No model calls

工具调度消融Tool scheduling

确定性消融：生产调度器重放 5/10/20 文件读取批次，对比强制串行与副作用感知并发调度；混合读写 workload 验证写操作不与其他工具重叠。结果仅反映工具执行阶段。Deterministic ablation: replay identical read batches through the production scheduler, comparing forced serial execution with side-effect-aware concurrency. Mixed read/write workloads verify writes never overlap other operations. Results reflect the tool-execution stage only.

Shell 
uv run python -m benchmarks.runners.run_tool_scheduling \
  benchmarks/tasks/parallel_reads \
  --repeat 10 --warmup 1
