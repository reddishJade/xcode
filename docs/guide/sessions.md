# 会话与上下文管理

Xcode 拥有极其严密的会话状态管理架构。本文档介绍 Xcode 的事实账本、分层上下文压缩、会话分支以及文件快照撤销机制。

---

## 1. 可回放事实账本 (Session Transcript)

在 Xcode 中，会话并非内存中的易失对象，而是以结构化 JSONL 文件落盘的 **Append-only 事实账本**（位于 `.xcode/sessions/<session-id>.jsonl`）：

* **事件类型**：
  * `inbox/inserted` / `inbox/claimed`：记录用户输入与消息生命周期；
  * `provider_request`：记录实际发给大模型的完整消息序列、Schema 及配置指纹；
  * `assistant` / `tool_use` / `tool_result`：记录运行时的模型输出与工具交互结果；
  * `compaction`：记录上下文压缩 epoch 与状态替换摘要；
  * `subagent_run`：记录子代理的调用谱系与最终结果。
* **日志投影机制**：所有会话状态、Todo 清单与模式设置均从日志流中确定性重建（Replay），确保随时可安全中断、恢复和回放。

---

## 2. 70% 智能水位线与分层压缩 (Layered Compaction)

长程多轮交互中，历史文件读取与海量工具输出容易耗尽上下文窗口。Xcode 的 `LayeredCompactor` 实现了智能分层压缩：

```
Context Window
┌─────────────────────────────────────────────────────────────┐
│ Stable System Prompt + Tools                                │
├─────────────────────────────────────────────────────────────┤
│ Verbatim Tail (最新轮次原文保留)                            │
├─────────────────────────────────────────────────────────────┤
│ Structured Checkpoint (结构化滚动摘要与任务状态 Replacement) │  ◄── 70% 水位线触发压缩
├─────────────────────────────────────────────────────────────┤
│ [Trimmed] 过期文件内容、大型工具结果被智能裁剪              │
└─────────────────────────────────────────────────────────────┘
```

1. **自动触发**：当 Token 使用量达到预留预算阈值（默认约 70%）时自动启动压缩；
2. **三级裁剪**：
   * 优先剔除重复且已过期的 `read_file` 原始全文；
   * 截断超大工具输出，保留关键头尾行；
   * 对旧轮次对话进行语义摘要，保留任务目标、架构决策与未完成的 Todo 清单；
3. **滚动 Checkpoint**：压缩结果作为 `compaction` 事件追加至账本。会话恢复时直接读取 `Checkpoint + 原文 Tail`，上下文重建只需几毫秒。

手动触发压缩：在 REPL 中输入 `/compact`。

## 3. 会话分支与树状浏览 (/fork, /tree)

当需要尝试不同的技术实现路线时，你可以随时分叉会话：

```text
# 从第 4 轮消息处分支新会话
/fork 4

# 查看当前项目的完整会话分叉树
/tree

# 克隆当前会话到新文件
/clone
```

分支操作会在独立文件中记录新谱系，原有会话历史绝不被污染。

---

## 4. 文件级快照原子撤销 (/undo)

当 Agent 修改了多个代码文件但未能解决问题，或者引入了不期望的变更时，Xcode 的文件快照引擎允许你一键秒级还原：

```text
# 查看最近可撤销的文件快照列表
/undo --list

# 撤销最近一次工具执行所产生的所有文件修改
/undo

# 连续撤销最近 3 次工具修改
/undo 3
```

快照撤销是原子性的，文件内容会精准恢复至执行前的 SHA256 状态。

---

## 5. 对话轮次回退 (/rewind)

如果需要撤销多轮对话的上下文（例如纠正提问方向）：

```text
# 撤销最近 1 轮问答交互
/rewind

# 撤销最近 3 轮交互
/rewind 3
```
