# 事故复盘

此目录保存影响真实用户路径、破坏核心不变量或暴露系统性验证缺口的正式复盘。
目标是改进系统，不归责个人。

## 触发条件

- 数据丢失、历史被改写或无法恢复；
- 权限、审批或本地执行边界被绕过；
- 模型看到未记录、错误或无法重建的上下文；
- 单测通过但真实 `build_app`、进程或 UI 路径失败；
- 同类问题重复出现，说明缺少系统性约束。

文件名使用 `NNNN-short-title.md`。从 `TEMPLATE.md` 复制，记录可验证事实、时间线、
违反的不变量、为何现有测试未发现，以及带 owner/status 的修复项。至少一个修复项
应是 assembled regression test。
